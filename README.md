# 🧠 Memory Booster

An interactive memory game designed to improve memory and concentration.

## 📌 About the Project

Memory Booster is a web-based brain-training application that helps users practise memory, attention, and concentration through interactive matching games. It provides an engaging and user-friendly experience for students and other users.

## ✨ Features

- User registration and login
- Interactive memory-matching game
- Multiple difficulty levels
- Multiple card themes
- Single-player and multiplayer modes
- Timer and score tracking
- Game history and performance statistics
- Leaderboard and achievements
- Responsive user interface
- Light and dark themes

## 🛠️ Technologies Used

- HTML5
- CSS3
- JavaScript (ES6+)
- PHP
- MySQL
- XAMPP

## ⚙️ Installation and Setup

1. Install XAMPP on your computer.
2. Clone or download this repository.
3. Place the project folder inside the XAMPP `htdocs` directory.
4. Start Apache and MySQL from the XAMPP Control Panel.
5. Open phpMyAdmin and create the `memory_booster` database.
6. Import `database.sql` if it contains the required database structure.
7. Configure the database connection in `config.php`.
8. Open the project in your browser:

   `http://localhost/memoryboosterupdate/`

## 🎮 How to Use

1. Open the website in your browser.
2. Register an account or log in.
3. Select a game mode, difficulty, and card theme.
4. Start playing and match the pairs.
5. View your score and game statistics.
